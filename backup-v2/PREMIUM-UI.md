## 🎨 Customization

### Change Brand Colors:
Edit `/assets/css/premium-theme.css`:

```css
:root {
  --primary: #6366f1; /* Change brand color */
  --primary-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
```

### Adjust Card Radius:
```css
:root {
  --radius-lg: 20px; /* Make cards more rounded */
}
```

### Modify Spacing:
```css
:root {
  --spacing-xl: 40px; /* Increase spacing */
}
```
